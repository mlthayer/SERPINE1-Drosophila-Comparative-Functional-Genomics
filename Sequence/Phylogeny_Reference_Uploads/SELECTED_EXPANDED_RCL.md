# Selected historical expanded-RCL phylogeny

The author selected the original expanded human/fly RCL maximum-likelihood tree
for reporting. Its Newick file is an unchanged copy of the supplied reference;
The source is 04D_expanded_human_fly_RCL_ML.nwk in this folder. The model-summary CSV
contains the corresponding unchanged row from the historical model summary.

## Disclosure for methods/results

The original expanded-RCL maximum-likelihood tree was retained as the reported
topology. Reanalysis of the identical alignment with the same JTT model produced
an alternative topology (Robinson–Foulds distance 8), with lower likelihood
(-704.7610 versus the originally reported -703.0975). A diagnostic fixed-topology
refit also favored the historical topology under the same current model/data
(approximately -703.0981 versus -704.7610). The difference is consistent with
alternative outcomes of the stochastic tree search; a platform-specific cause
or global likelihood optimum was not established. Both results are preserved.
This phylogenetic comparison contributes no term to the integrated ranking.

## Support-label limits

The historical model summary reports 500 bootstrap replicates. The original
replicate trees/model object and label-definition record are unavailable.
Internal labels in the supplied Newick are retained verbatim for provenance,
but must not be described as independently verified bootstrap percentages.
Some labels are not increments expected for simple 500-replicate proportions.
No new support statistics were generated.
Do not infer well-supported functional equivalence from a short RCL tree.

The current single-search rerun and its complete local checkpoint remain separate
from the selected historical output. No search method, model, seed or bootstrap
parameter was changed to force agreement.
