# Per-system match reference outputs

Preserved fourteen original comparison tables. Verified all 660 signed and
absolute differences, male/female subsets, SERPINE1 subsets and rank-1
best-match filtering. These rank fly candidates within individual biological
systems by expression difference. They are not the per-profile composite
similarity or cross-dataset consensus used by step 10.

No Mean_Composite_Similarity or corresponding generating equations are
provided in these files. Do not substitute per-system match ranks for the
integrated bulk-expression domain or invent a composite formula.

Path_Check.csv contains 14 machine-specific absolute locations. The original
remains in the session's uploaded attachments for review and is not copied
into the public repository. Path_Check_Publication_Safe.csv explicitly flags
those rows while preserving file labels. No analytical data were removed.
Exact local source locations and usernames should not be published.
